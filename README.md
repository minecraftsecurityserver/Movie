# 🎬Movie

Minecraft Bedrock Kinowelt mit 3 Filmen in voller Länge.

## 🎞 Die Filme
1. **VDOX Kurzfilm** (4:00) — CinemaMap Original
2. **MIMIC — A Short Horror Film** (5:15)
3. **Musikparodie** — "Is mir egal" (2:57)

## ▶️ Befehle
```
/function bauen   – Kino bauen
/function tp      – hinein teleportieren
/function filme   – Programm anzeigen
/function play1   – Film 1 (VDOX)
/function play2   – Film 2 (MIMIC Horror)
/function play3   – Film 3 (Musikparodie)
/function stop    – Film beenden
```
